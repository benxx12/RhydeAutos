# RhydeAutos

A responsive car dealership website for RhydeHaus, built with React and Tailwind CSS.

## Features

- Home, About, Contact, inventory, and vehicle detail pages.
- Vehicle inventory with search, body-style filters, sorting, and pagination.
- Car detail galleries with exterior, rear, and interior photos.
- Responsive layouts and mobile navigation.

Vehicle images are representative reference photos; see [`public/images/ATTRIBUTION.md`](public/images/ATTRIBUTION.md) for credits.

## Getting started

Install dependencies with `npm install`, then run:

```sh
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).

## Available scripts

- `npm test` — run the test suite.
- `npm run build` — create an optimized production build in `build/`.
